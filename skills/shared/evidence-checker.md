# Evidence Checker

Purpose: keep facts, results, assumptions, and recommendations distinct.

Tag important statements internally as:
- **F0 — source fact**: directly supported by supplied/public evidence.
- **F1 — user result**: supplied experimental/numerical result, not independently verified.
- **I — inference**: reasoned conclusion from evidence.
- **H — hypothesis**: proposed explanation or expected outcome.
- **A — assumption**: adopted to proceed.
- **R — recommendation**: what should be done.

Rules:
1. Never silently upgrade I/H/A into F0.
2. Quantitative claims need a traceable source or must be labeled as targets/estimates.
3. A proposal target is not an achieved result.
4. A numerical demonstration is not automatically experimental validation.
5. Reviewer comments should distinguish missing evidence from incorrect results.
6. If external facts are time-sensitive or niche, verify them before using them as anchors.
