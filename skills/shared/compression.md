# Compression and Re-expression

Purpose: shorten scientific content without breaking its logic.

## Preserve in this order

1. problem / need;
2. scientific question or central claim;
3. proposed mechanism or method;
4. differentiating evidence;
5. outcome / implication.

Remove first:
- generic motivation;
- repeated adjectives;
- implementation detail not needed by the audience;
- multiple examples proving the same point;
- background facts already encoded in a figure.

## Standard transformations

- **One sentence**: problem + method + intended change.
- **150–250 words**: context, gap, approach, expected contribution.
- **One slide**: title as conclusion + 3 evidence blocks + one bottom-line takeaway.
- **3-minute talk**: why it matters → what is missing → what we will do → why it can work.
- **10-minute talk**: add evidence, route, milestones, and key risks.

Never compress by deleting the logical hinge between problem and method.
