# Example 05 — Title should name the real defect and domain

## Trigger
> “On moment conservation in adaptive mesh refinement” 这个标题是不是太泛？是不是把 kinetic equations 直接写出来？

## Mode
`paper-master` — Author mode

## Key judgment
A title should identify the scientific object, the defect/problem, and the contribution type without using terminology that is ambiguous outside the intended community.

## Pattern to reuse
- Prefer the physical/mathematical domain when a method term is ambiguous.
- Use “defect”, “analysis”, “correction strategy/procedure” only if each is a real paper contribution.
- Avoid a title that implies all AMR when the issue is specific to velocity-space discretization.

## Ideal response shape
Compare 2–4 title variants against:
- scope accuracy;
- novelty visibility;
- terminology naturalness;
- overclaim risk.
Then recommend one.

## Failure to avoid
- Optimizing elegance while leaving the scope scientifically ambiguous.
