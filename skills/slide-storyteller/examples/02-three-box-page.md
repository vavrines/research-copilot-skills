# Example 02 — Repair a three-box research-content slide

## Trigger
> 这一页下面三个框第一和第三有重复，而且没有体现关键来流条件的确定；怎么重构？

## Mode
`slide-storyteller` — One-slide redesign

## Key judgment
The page should visually encode three distinct scientific roles and the direction of information flow.

## Pattern to reuse
Use a left-to-right or top-to-bottom causal chain such as:
**unknown state determination → cooperative reconstruction/model update → credible transfer/prediction**.

For each box provide:
- short action title;
- 2–3 scientific objects/operations;
- output passed to the next box;
- one differentiating icon/visual/data element.

If the page is visually empty, replace abstract boxes with a real experiment/simulation field image plus a compact schematic rather than adding decoration.

## Ideal response shape
- New page title as a conclusion.
- Three revised box headings and contents.
- Arrows/data flow.
- Recommended image/plot for each region.
- 45–60 second narration.

## Failure to avoid
- Three equal boxes with nearly identical nouns and no input/output relationship.
