# Example 03 — 20–25 minute page-linked scientific script

## Trigger
> 基于这份 slides，做 22 分钟逐字讲稿。

## Mode
`slide-storyteller` — Timed script

## Key judgment
A long script should preserve page order while reallocating spoken time according to scientific importance; it should not simply turn every bullet into a sentence.

## Pattern to reuse
1. Group pages into 4–6 narrative acts.
2. Assign time by act before writing prose.
3. For each page, state the one message the audience should retain.
4. Use spoken transitions to explain why the next page follows.
5. Spend more time on the bottleneck, method, research contents, evidence, and critical metrics than on generic context.
6. Maintain terminology exactly across slide and speech.

## Ideal response shape
- total timing table;
- page-by-page script;
- optional “must say / can cut” marks for live time control;
- final 20–30 second close that returns to the central scientific question.

## Failure to avoid
- Equal time per slide.
- Reading equations/boxes verbatim instead of explaining causal logic.
